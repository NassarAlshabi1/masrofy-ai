# مصروفي AI — قالب بناء تطبيقات أندرويد APK مجاناً بدون Android Studio 🚀

قالب جاهز لتحويل أي تطبيق ويب مصمم بـ **Google Stitch + Google AI Studio** إلى ملف أندرويد **`APK`** جاهز للتثبيت عبر **Capacitor + GitHub Actions** مجاناً في دقيقتين وبدون تثبيت برامج ثقيلة.

## الملفات الأساسية الثلاثة
- `www/index.html` — ملف التطبيق التفاعلي الكامل (يعمل أوفلاين باللغة العربية RTL).
- `capacitor.config.json` — إعداد اسم التطبيق (`appName`) والمعرف الفريد (`appId`).
- `.github/workflows/build-apk.yml` — ماكينة البناء السحابية التلقائية لإخراج `Masrofy-AI-Android-APK`.
